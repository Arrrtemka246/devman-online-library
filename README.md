# Библиотека Максима

Каталог 92 книг с обложками, авторами и жанрами. Статический сайт, который можно
читать в интернете или открыть с диска без установки программ.

**[Открыть библиотеку](https://arrrtemka246.github.io/devman-online-library/)**

## Скачать и читать без интернета

1. [Скачайте ZIP с библиотекой](https://github.com/Arrrtemka246/devman-online-library/archive/refs/heads/main.zip).
2. Полностью распакуйте архив в любую папку.
3. Откройте `index.html` двойным щелчком в браузере.
4. Выберите страницу по номеру или нажмите «Вперёд», затем «Читать» у книги.
   Текст откроется в новой вкладке. Интернет и Python для этого не нужны.

Сохраняйте папки `media/`, `static/`, `pages/` и остальные файлы вместе:
ссылки относительные, поэтому библиотеку можно переносить целиком.

## Изменить сайт

Для разработки нужен Python 3.10 или новее. В терминале перейдите в папку проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python render_website.py
```

В Windows вместо команды активации используйте `.venv\Scripts\activate`.
Откройте <http://127.0.0.1:5500/>. Скрипт напечатает число книг и страниц.
Изменения `template.html` и данных автоматически пересобирают HTML и обновляют браузер.
Чтобы остановить сервер, нажмите Ctrl+C.

Только пересобрать готовые HTML-файлы:

```sh
python render_website.py --build
```

Дополнительные параметры:

```sh
python render_website.py --metadata meta_data.json --books-per-page 20 --port 5500
```

Страницы создаются в `pages/index1.html`, `pages/index2.html` и далее; в корне
есть готовая первая страница `index.html`. Лишние сгенерированные страницы при
уменьшении списка книг удаляются автоматически. На широком экране две колонки,
на узком — одна. В каждой странице до 20 книг, кнопки краёв заблокированы,
текущий номер выделен синим. Все ресурсы локальные; JavaScript сайту не требуется.

## Данные

Источник — [учебный архив Devman](https://dvmn.org/filer/canonical/1744271653/1019/)
с книгами библиотеки [tululu.org](https://tululu.org/). Данные предоставлены в уроке.
Тексты хранятся в `media/books/`, обложки — в `media/img/` (при отсутствии обложки используется
`media/img/nopic.gif`). Метаданные — `meta_data.json`, список объектов:

```json
[
  {
    "title": "Название книги",
    "author": "Автор",
    "img_src": "img/nopic.gif",
    "book_path": "books/example.txt",
    "genres": "Фантастика, Приключения.",
    "comments": []
  }
]
```

Тексты и JSON должны быть в UTF-8. Жанры также можно задать списком строк.
Пути книг и обложек в JSON задаются относительно `media/`, включая каталоги `books/` и `img/`.
Пробелы, кириллица и специальные знаки в ссылках кодируются автоматически;
обратные слеши из Windows заменяются прямыми. HTML из метаданных экранируется.

Bootstrap 4.6.2 лежит локально в `static/bootstrap.min.css`, лицензия —
`static/BOOTSTRAP-LICENSE.txt`; там же хранится фавикон `static/favicon.svg`. Изменили шаблон или данные — пересоберите страницы,
закоммитьте их вместе с исходниками. Для публикации в Settings → Pages выберите
Deploy from a branch, ветку `main`, папку `/ (root)`.

Учебный проект курса [«Вёрстка для питониста» Devman](https://dvmn.org/modules/website-layout-for-pydev/).
